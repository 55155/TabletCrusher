## SMC ZM101H-K5LZ
형번 해석 (`docs/SMC_ZM_catalog_KR.pdf` p.176 형식표시방법):

| 자리 | 코드 | 의미 |
| --- | --- | --- |
| 노즐 지름 | 10 | 1.0 mm |
| 몸체 형식 | 1 | 단품, 밸브 + 표준 소음기 |
| 표준 공급압력 | H | 0.5 MPa |
| 밸브 조합 | K | 공급밸브(N.C.) + 파괴밸브 |
| 정격 전압 | 5 | DC24V |
| 리드선 | L | L형 플러그 커넥터, 리드선 0.3 m |
| 보호회로 | Z | 램프·서지전압 보호회로 부착 |
| 진공 스위치 | (없음) | 스위치 없음 |

사양 (p.178):

| 항목 | 값 |
| --- | --- |
| 최대 흡입유량 | 50 L/min (ANR) |
| 공기 소비량 | 60 L/min (ANR) |
| 최고 진공압력 | −84 kPa |
| 공급압력 범위 (밸브 부착) | 0.25 ~ 0.55 MPa |
| 최고 사용압력 | 0.7 MPa |
| 솔밸브 소비전력 | DC 1 W (램프 부착 1.05 W) |
| 석션 필터 | 30 µm, PE |
| 사용 온도 | 5 ~ 50 °C (밸브 부착) |

공급밸브 ON → 진공 발생, 공급밸브 OFF + 파괴밸브 ON → 진공 파괴(워크 이탈).
DC 타입은 극성 오결선 시 보호 다이오드 소손 주의.

## 비틀벅 BBT-001 (에어 컴프레서)
판매처 상세페이지 종합. 제조사 공식 사양서는 찾지 못함.

| 항목 | 값 |
| --- | --- |
| 탱크 용량 | 3 L |
| 전원 | 단상 220 V |
| 방식 | 무오일, 압력 스위치 자동 ON/OFF, 레귤레이터, 수분 필터 |
| 외형 | 높이 31.5 × 가로 29 × 세로 14 cm |
| 중량 | 약 5.2 kg |
| 사용 압력 | 4 bar (현장 사용값) |
| 최대 압력 / 토출량 | 판매처 표기 없음 |

### 조합 확인 사항
- 공급압력: 4 bar(0.4 MPa)는 ZM 밸브 부착형 범위(0.25~0.55 MPa) 안이지만 H형 표준(0.5 MPa)보다 낮다.
- 유량: 이젝터 연속 흡착 시 60 L/min을 소비한다. 컴프레서 토출량이 미확인이라 탱크 3 L로 버티는 시간은 실측 필요.
