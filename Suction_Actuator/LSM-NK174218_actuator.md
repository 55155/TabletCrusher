# LSM-NK174218-xxxx — 리니어스테이지 + 스텝모터 (모터뱅크)

실제 구동되는 물리 액추에이터(리니어스테이지+모터) 스펙 문서. 제어 드라이버(SBD-14U) 쪽 문서는 [`Suction_actuator.md`](Suction_actuator.md) 참조.

## 개요
- 리니어스테이지와 2상 바이폴러 스텝모터가 일체형으로 결합된 1축 제어용 제품
- 스크류 직경/리드는 모델 접미사(`-1204`, `-1605`, `-1610` 등)별로 상이 — 아래 표 참조, **실제 받은 제품의 접미사 확인 필요**
- 리미트센서는 기본 미포함 — 필요 시 별도 장착 (SN04-N 예시)

## 모터 스펙
| 항목 | 값 |
|---|---|
| 상수(PHASE) | 2상 바이폴러 |
| 스텝각 | 1.8°/step (200 step/rev, 마이크로스텝 적용 전 기준) |
| 상당전류 | **1.5 A/phase** |
| 디턴트토크 | 0.52 Nm |
| 공급전압 | DC 10~36V |
| 리드와이어 | 4선 |
| 모터중량 | 370 g |
| 샤프트 | Φ5mm, 길이 24mm |
| 온도상승 | 85K Max |
| 환경온도 | -40 ~ +55℃ |
| 절연등급 | B급 |

> **SBD-14U 드라이버로 구동 시 참고**: 드라이버 운전전류 설정값(0-31)은 `I=(값+1)/32*2A`이므로, 모터 정격 1.5A/phase에 맞추려면 설정값 **23** 근처(`(23+1)/32*2A=1.5A`)가 적정. 이전 테스트에서 run=10(≈0.69A)로는 부하 대비 전류 부족으로 탈조(진동만 하고 전진 안 함) 가능성이 있었음 — 초기속도 문제와 함께 전류도 같이 올려서 재확인할 것.

### 분주비(microstep)별 pulse/mm 환산
`pulse/mm = (200 step/rev × 분주비) / Lead(mm)`

| Lead | 분주비 4 | 분주비 16 | 분주비 32 | 분주비 256(현재 SBD-14U 설정값) |
|---|---|---|---|---|
| 4mm (-1204) | 200 | 800 | 1,600 | 12,800 |
| 5mm (-1605) | 160 | 640 | 1,280 | 10,240 |
| 10mm (-1610) | 80 | 320 | 640 | 5,120 |

좌표모드(0x002B)로 절대위치 이동 시, 목표 mm × 위 표의 pulse/mm 값을 steps로 환산해서 넣으면 됨.

## 전기적 특성 (스테이지+모터 전체 시스템 기준)
- 공급전압: DC 10V ~ 35V (추천: DC24V)
- 공급전류: **최대 6A 이상 필요** (스테이지 자료 기준 — 모터뱅크가 참조로 제시한 MSD-224 드라이버 기준 수치로 보임. SBD-14U 사용 시에는 SBD-14U 자체 한계인 2A/phase, 드라이버 소비 12W 기준치 적용)

## 모터 결선 (커넥터 색상 — 제품별 2가지 버전 존재, 반드시 실물 확인)
| | A+ | A- | B+ | B- |
|---|---|---|---|---|
| 커넥터 1 | 빨강 | 파랑 | 블랙 | 초록 |
| 커넥터 2 | 빨강 | 녹색 | 노랑 | 파랑 |

**주의: 색상코드 두 버전 중 하나로 받게 되니, 결선 전 실제 케이블 색을 모터뱅크 표와 대조해서 확인할 것.** 상(phase) 매칭이 틀리면 탈조/역방향 동작 가능.

## 리미트/엔드센서 (옵션, 미포함 — 필요 시 직접 장착)

### SN04-N (근접센서, 예시)
| 항목 | 값 |
|---|---|
| 타입 | 광전 리미트 스위치 (방수) |
| 사이즈 | 18×18×36mm |
| 전압 | DC 10~30V |
| 전류 | 300mA |
| 감지거리 | 4mm (금속 전용: 철/금/은/구리 등) |
| 결선 | 검정(신호출력), 갈색(DC10~30V 전원), 청색(GND) |

- 통상 DC24V 인가 + 검정 신호선을 수신 입력으로 연결
- X1(모터에 가까운 쪽) / X2(먼 쪽) 2개 설치해서 양 끝단 리미트로 사용
- SBD-14U 쪽 리미트 입력은 **NPN 타입만 호환** — SN04-N이 NPN 출력인지 확인 필요 (스펙시트상 타입 명시 없음, 추가 확인 권장)

### 엔드센서(별도 커넥터 타입)
- Φ2.8 4PIN, 케이블 길이 2000mm
- 결선: Blue(GND), Brown(DC5V~24V), Black(NC), White(NO)

## 참고: 모터뱅크 제시 레퍼런스 드라이버 구성 (본 프로젝트는 SBD-14U 사용, 비교용)
매뉴얼 예시 연결구성도는 **MSD-224(스텝/방향 펄스 입력 드라이버) + SPLS-2D(속도조절 컨트롤러)** 조합 기준이며, 이는 PUL/DIR/ENA 펄스 방식 제어입니다. 본 프로젝트는 RS-485 Modbus 방식인 **SBD-14U**를 사용하므로 이 펄스 드라이버 결선(PUL-/PUL, DIR-/DIR, ENA-/FRE 등)은 해당 없음 — 모터 A+/A-/B+/B- 결선만 참고.
